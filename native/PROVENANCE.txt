native\build-helper.ps1, native\build-deepfilter.ps1, native\build-webrtc-apm.ps1, native\fetch-models.ps1 and
native\export-models.ps1 with the script in native\export\). Licenses and copyright notices: see THIRD-PARTY-NOTICES.txt.
Each is built for x64 (.build\native) and, with -Arch arm64, for Arm64 (.build\native-arm64) from the same source;
"arm64:" lines below list what differs. The Arm64 build runs on x64 or Arm64 Windows (cross-compiling as needed) and
also needs the MSVC ARM64 tools and clang-cl (Visual Studio components Microsoft.VisualStudio.Component.VC.Tools.ARM64
and Microsoft.VisualStudio.Component.VC.Llvm.Clang).
